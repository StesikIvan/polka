# Полка

Каталог домашней коллекции настольных игр: что есть и **где именно оно лежит**.

**Открыть:** https://stesikivan.github.io/polka/

## Что умеет

- **Квартира** — дерево мест как в приложении умного дома: комната → мебель → конкретная полка. В любой уровень можно зайти и увидеть, что там лежит.
- **Коллекция** — сетка обложек, поиск по названию, тегу и месту, сортировка.
- **Что сыграть** — подбор по числу игроков, времени и своим тегам, плюс «выбери за меня».
- **Добавление** — по одной или сразу списком; название, обложка, игроки, время, возраст и рейтинг подтягиваются с [tesera.ru](https://tesera.ru) живым запросом.
- Отметка «одолжена» — видно, что игра не дома, а у кого-то.

## Как считаются категории

«Всей семьёй», «битва умов», «гик-тусовка», «большой компанией», «пьянка» —
не спрашиваются при добавлении, а выводятся из данных Тесеры: `timeToLearn`
(сколько минут объяснять правила), возраст, число игроков, длительность.
Спрашивать человека о каждой коробке — верный способ бросить каталог на пятой.

В карточке игры автоматику можно перещёлкнуть вручную. Ручная пометка
записывается в `vibes` и всегда важнее вычисленной.

## Синхронизация между устройствами

Общее хранилище — секретный gist на GitHub. Сервера нет, платить не за что.
Читается он по одному номеру, пишется только с токеном (classic PAT, галочка
`gist` и больше ничего). Токен лежит в `localStorage` устройства.

Слияние идёт **по каждой записи отдельно**, а не «чей файл новее»: иначе игра,
добавленная с одного телефона, затирала бы правки, сделанные на другом. У каждой
игры и места есть `updatedAt`, у удалённых — надгробие в `trash`, чтобы удаление
не откатывалось назад при следующем обмене. Надгробия старше трёх месяцев
выбрасываются.

Обмен запускается при открытии приложения, при возврате к вкладке, при появлении
связи и через 2,5 с после последней правки.

Второе устройство подключается ссылкой вида `#/connect/<код>` — внутри неё номер
хранилища и токен, вводить руками ничего не нужно. **Ссылку надо беречь как
пароль.**

## Где живут данные

На устройстве, в `localStorage` браузера. Если синхронизация не включена —
больше нигде.
Каталог игр внутрь приложения не зашит — поиск каждый раз идёт в API Tesera,
поэтому новые игры находятся без обновления приложения.

Копия коллекции: **Настройки → Сохранить копию** (файл JSON) или
**Скопировать в буфер**. Оттуда же — загрузка обратно.

## Локальный запуск

```bash
node serve.mjs
```

Дальше http://localhost:8787

## На айфоне

Открыть адрес в Safari → «Поделиться» → **«На экран Домой»**.
Дальше запускается как обычное приложение и работает офлайн.

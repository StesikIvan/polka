# Полка

Каталог домашней коллекции настольных игр: что есть и **где именно оно лежит**.

## Что умеет

- **Квартира** — дерево мест как в приложении умного дома: комната → мебель → конкретная полка. В любой уровень можно зайти и увидеть, что там лежит.
- **Коллекция** — сетка обложек, поиск по названию, тегу и месту, сортировка.
- **Что сыграть** — подбор по числу игроков, времени и своим тегам, плюс «выбери за меня».
- **Добавление** — по одной или сразу списком; название, обложка, игроки, время, возраст и рейтинг подтягиваются с [tesera.ru](https://tesera.ru) живым запросом.
- Отметка «одолжена» — видно, что игра не дома, а у кого-то.

## Где живут данные

Только на устройстве, в `localStorage` браузера. Ничего никуда не отправляется.
Каталог игр внутрь приложения не зашит — поиск каждый раз идёт в API Tesera,
поэтому новые игры находятся без обновления приложения.

Копия коллекции: **Настройки → Сохранить копию** (файл JSON) или
**Скопировать в буфер**. Оттуда же — загрузка обратно.

## Локальный запуск

```bash
node serve.mjs
```

Дальше http://localhost:8787

## На айфоне

Открыть адрес в Safari → «Поделиться» → **«На экран Домой»**.
Дальше запускается как обычное приложение и работает офлайн.
